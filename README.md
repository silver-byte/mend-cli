mend is one command-line tool that applies the edits AI models write, in all four formats — unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, the V4A patch format and text-editor tool calls as JSON — to a tree of text files, exactly as SPEC.md specifies. It finds the lines each edit names at the first of three matching tiers, even when the model drifted their whitespace or indentation, and changes every file or none.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
